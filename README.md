## 🔬 Current Research

My work focuses on using computational biology, multi-omics
and machine learning to investigate biological mechanisms
underlying human disease.

### Current areas

- 🫁 **Respiratory disease and COPD**
- 🧬 **Respiratory microbiome**
- 🔬 **Single-cell transcriptomics**
- 🧪 **Multi-omics integration**
- 🤖 **Machine learning for biological prediction**
- 🧠 **Interpretable AI and biological discovery**
- 🧫 **Disease and cancer genomics**
